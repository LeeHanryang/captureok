# M2 수동 확인 목록

표기: [x] 확인됨 (확인한 사람·방법), [~] 일부 확인, [ ] 미확인

## M2-1 새 편집 창
- [x] 캡처하면 편집 창이 맨 앞에 뜨고 제목이 `CaptureOK — 가로 × 세로` (개발자: 키보드 스모크)
- [x] Esc로 숨긴 뒤 새로 캡처하면 같은 창이 다시 맨 앞에 뜨고 제목이 바뀐다 (개발자: 키보드 스모크)
- [x] Ctrl+C 복사 후에도 창이 열려 있다 (개발자: 키보드 스모크)
- [ ] 창 모양: Windows 11 스타일(둥근 모서리, Mica 배경), Windows 다크·라이트 설정을 따라간다
- [ ] 도구 막대: 도구 13개 아이콘 + 툴팁(이름·단축키), 그룹 구분선, 오른쪽에 실행 취소·다시 실행·확대 비율·복사·저장·목록
- [ ] 도구 버튼을 누르거나 단축키(V P H R E L A T N M B C X)를 누르면 하나만 선택되고 상태 표시줄 도움말이 바뀐다
- [ ] Ctrl+휠로 확대·축소(10~800%), Ctrl+0 = 100%, 확대 비율 표시가 맞다
- [ ] 저장(버튼·Ctrl+S): 위치 선택 창, 마지막 폴더 기억, 저장 후 창 유지, 상태 표시줄 "저장됨: 이름"
- [ ] 저장 창에서 취소하면 상태 표시줄이 바뀌지 않는다
- [ ] 같은 캡처를 다시 저장하면 그때 시각으로 새 이름을 제안하고, 같은 이름을 고르면 덮어쓰기 확인이 뜬다
- [ ] 저장 창이 열려 있는 동안 PrintScreen으로 새로 캡처해도, 저장을 마치면 처음 캡처만 "저장됨"이 되고 새 캡처는 저장 안 함으로 남는다
- [ ] 트레이 아이콘 한 번 클릭 = 영역 지정 캡처 (조금 늦게 시작됨), 더블클릭 = 편집 창만 열림 (캡처 안 됨)
- [ ] 한글 입력 상태(한/영 키로 한글)에서도 도구 단축키(P, R 등)가 동작한다
- [ ] "목록" 버튼으로 오른쪽 패널이 열리고 닫히며, 다시 실행해도 상태가 유지된다
- [ ] X 버튼 = 숨김 (앱은 트레이에 남음), 트레이 아이콘 더블클릭 = 편집 창 다시 열기
- [ ] 트레이 "종료": 저장·복사하지 않은 캡처가 있으면 편집 창 위에 확인 창이 뜨고, "아니요"면 종료하지 않는다
- [ ] 캡처 오버레이(드래그 화면)의 모습이 M1과 같다 (WPF-UI 영향 없음)

## M2-2 그리기 도구
- [x] 사각형을 그리면 복사 결과에 그려지고, Ctrl+Z로 지우면 복사 결과에서도 사라진다 (개발자: 자동 마우스 스모크, 빨강 0 → 1,708 → 0)
- [ ] 펜: 자유롭게 그려지고 Shift를 누르면 직선, 클릭 한 번 = 점
- [ ] 형광펜: 반투명·굵게, 한 획 안에서 겹친 곳이 진해지지 않음, Shift = 직선
- [ ] 사각형·원: Shift = 정사각형·정원, 채우기 켜면 채워진 도형, 점선 켜면 점선 테두리
- [ ] 직선·화살표: Shift = 45도 단위, 화살표 머리가 끝에 붙음, 점선 가능
- [ ] 번호: 누를 때마다 1, 2, 3…, 밝은 색(노랑·흰색)이면 숫자가 검정
- [ ] 텍스트: 누른 곳에 한글 입력, Enter = 줄바꿈, 바깥 클릭·Esc·Ctrl+Enter = 완료, 저장 결과의 글자 위치가 입력 위치와 같음
- [ ] 텍스트: 입력 중 P·R·Ctrl+C·Esc 같은 키가 도구 전환·복사·창 숨김으로 동작하지 않음
- [ ] 텍스트: 한글을 조합하는 중에 바깥을 눌러도 마지막 글자가 사라지거나 두 번 들어가지 않음
- [ ] 선택 도구로 텍스트 더블클릭 = 다시 편집, 내용을 모두 지우고 끝내면 객체 삭제
- [ ] 선택(V): 객체 클릭 = 파란 점선 테두리, 드래그 = 이동, Delete = 삭제, Ctrl+Z로 이동 취소
- [ ] 지우개(X): 객체를 누르면 지워짐, 모두 지우기 버튼·Ctrl+Delete
- [ ] 색 메뉴(8색 + 사용자 지정), 굵기 1·2·3·5·8, 바꾼 색·굵기는 다음 캡처에도 유지
- [ ] 확대율 50%·200%에서 그린 위치와 저장 결과가 같음
- [ ] 아주 길게 펜을 그어도 버벅이지 않음
- [ ] 그리는 도중 Ctrl+Z를 누르거나 새로 캡처해도 이상한 객체가 남지 않음

## M2-3 모자이크·블러·자르기
- [x] 자르기(C)로 영역을 드래그하고 Enter → 창 제목·복사 크기가 자른 크기, 그 위에 그린 사각형이 복사 결과에 들어가고, Ctrl+Z로 원본 크기로 돌아온다 (개발자: 자동 마우스 스모크, 1280×720 → 300×180 → 1280×720)
- [x] 모자이크를 사각형 위에 그리면 그 부분의 사각형이 가려진다 (개발자: 스모크, 빨강 580 → 420)
- [ ] 모자이크(M): 드래그하는 동안 점선 영역, 놓으면 모자이크 적용. 칸 크기 8·12·16·24에 따라 굵기가 달라짐
- [ ] 블러(B): 놓으면 흐려짐. 세기 약·중·강이 눈에 띄게 다르고, 가장자리가 자연스러움
- [ ] 모자이크·블러 영역을 선택 도구로 옮기면 새 위치의 원본이 모자이크·블러됨 (원래 자리는 다시 선명)
- [ ] 이미지 바깥까지 드래그해도 이미지 안쪽만 적용됨, 클릭만 하면 아무것도 생기지 않음
- [ ] 자르기: 자르기 도구를 누르면 원본 전체가 보이고 지금 자른 영역이 표시됨, 바깥은 어둡게
- [ ] 자르기: Esc = 고른 영역 취소 (창은 숨지 않음), 다시 C 후 원본 전체를 고르고 Enter = 자르기 해제
- [ ] 자른 상태에서 그린 객체·텍스트 위치가 저장 결과와 같음 (확대율 50%·200%에서도)
- [ ] 큰 화면 전체 캡처에서 블러를 크게 그려도 놓을 때 1초 넘게 멈추지 않음

## M2-3 보완 (써 보고 받은 의견)
- [x] 지우개(X)로 사각형 두 개를 한 번에 문지르면 둘 다 지워지고, Ctrl+Z 한 번에 둘 다 돌아온다 (개발자: 마우스 스모크, 빨강 1,820 → 0 → 1,820)
- [x] 자르기(C)를 누르면 사진 전체가 손잡이 8개와 함께 선택되고, 왼쪽 변을 안으로 끌어 Enter하면 그만큼 줄어든다 (개발자: 스모크, 1280 → 1027)
- [x] 모자이크를 드래그하는 동안에도 모자이크가 보인다 (개발자: 스모크 화면 캡처)
- [x] 1280×720 캡처가 편집 창에 다 보이도록 자동으로 줄어든다 (개발자: 스모크, 79%)
- [ ] 블러를 화면 전체 크기로 드래그해도 마우스가 끊기지 않고, 블러가 살짝 늦게 따라온다
- [ ] 자르기: 모서리 = 대각선 커서로 두 변, 안쪽 = 이동 커서로 영역 이동, 바깥 드래그 = 새로 고르기, 크기 표시가 Enter 결과와 같음
- [ ] 자르기 상태에서 그대로 Enter·같은 영역 Enter는 실행 취소 목록에 남지 않음
- [ ] 다크·라이트 모드 모두 도구 아이콘이 잘 보이고, 선택된 도구·저장·목록 버튼이 차분한 회색(파란색 아님)
- [ ] 확대율 숫자를 누르면 다시 창에 맞춤, Ctrl+휠·Ctrl+0으로 바꾼 뒤에는 창 크기를 바꿔도 확대율 유지
- [ ] 작은 캡처는 100%로 열리고 흐려지지 않음, 작은 모니터에서는 편집 창이 화면 안에 들어옴

## M2-4 캡처 목록
- [x] 캡처 3번 → 목록에 3개, 최신이 위, 지금 캡처는 파란 테두리 (개발자: 마우스 스모크)
- [x] 두 번째 캡처에 그린 사각형이 다른 캡처로 갔다 와도 남아 있음 (개발자: 스모크, 빨강 960 → 0 → 960)
- [x] 고정 후 앱을 강제로 꺼도 다시 켜면 목록에 고정 캡처가 사각형째 돌아옴 (개발자: 스모크)
- [x] 구분선을 끌면 목록 폭이 바뀌고 다음 실행에도 유지 (개발자: 스모크, 200 → 300)
- [ ] 썸네일 아래 시각·크기, 저장·복사 안 한 캡처는 주황 점, 저장·복사하면 점이 사라짐
- [ ] 우클릭 메뉴: 저장·복사·고정/고정 해제·삭제가 그 캡처에 대해 동작 (지금 보고 있지 않은 캡처도)
- [ ] 11번째 고정 → "고정은 10개까지입니다", 고정 해제하면 보관 폴더(%LOCALAPPDATA%\CaptureOk\pinned)에서도 사라짐
- [ ] 목록 항목을 누른 뒤 Delete = 캡처 삭제, 캔버스를 누른 뒤 Delete = 선택한 객체 삭제 (캡처는 그대로)
- [ ] 저장 안 한 캡처 삭제·목록 비우기는 확인 창, 비우기 뒤 고정 캡처만 남고 지금 캡처가 지워졌으면 다른 캡처(없으면 "캡처가 없습니다")로
- [ ] 텍스트 입력 중·자르기 영역을 고른 채 다른 캡처로 바꿔도 이전 캡처에 섞이지 않음
- [ ] 모두 저장: 폴더를 고르면 목록 전체가 찍은 시각 이름으로 저장되고 주황 점이 모두 사라짐 (같은 초에 찍은 것도 덮어쓰지 않음)
- [ ] 최대 개수(30)를 넘으면 오래된 캡처가 빠지고, 저장 안 한 것이 빠졌으면 상태 표시줄에 알림
- [ ] 트레이 아이콘 더블클릭: 캡처를 안 했어도 편집 창이 열림 (고정 캡처가 있으면 그 캡처, 없으면 "캡처가 없습니다")

## M2-5 환경설정
- [x] 설정 창의 스위치를 켜고 끄면 settings.json에 바로 저장됨 (개발자: 스모크)
- [ ] 편집 창 톱니바퀴·트레이 "환경설정"으로 같은 설정 창이 열리고, 이미 열려 있으면 앞으로 나옴
- [ ] 일반: 테마 시스템·라이트·다크가 열려 있는 편집 창·설정 창에 바로 적용, Windows 시작 시 실행이 실제로 켜고 꺼짐
- [ ] 단축키: 칸을 누르고 새 조합을 누르면 바뀌고 트레이 메뉴 표시도 바뀜, 다른 기능과 겹치면 알림, 칸에 초점이 있는 동안 캡처 단축키가 동작하지 않음
- [ ] 단축키: PrtSc 단독도 지정되고, 다른 프로그램이 쓰는 조합이면 "등록하지 못함" 표시
- [ ] 저장: 폴더·파일 이름 규칙·형식을 바꾸면 다음 저장부터 적용
- [ ] 고정 크기: 크기를 추가·삭제하면 고정 크기 캡처 목록에 반영
- [ ] 캡처 목록: 최대 개수·패널 폭·비우기 확인 설정이 편집 창에 반영
- [ ] 기본값으로 되돌리기는 그 페이지만 되돌림
- [ ] settings.json을 망가뜨려도 앱이 꺼지지 않고 기존 설정을 유지
- [ ] 정보: 버전·만든 사람(LeeHanryang, GitHub 주소)·라이선스·제3자 고지가 보임

## M3 창·요소 자동 감지
- [x] 요소 캡처에서 탐색기 파일 목록 위에 커서를 두면 목록 경계가 잡힘 (개발자: 스모크, 1213×884)
- [ ] 영역 지정 캡처에서도 커서 아래 창·요소에 테두리가 생기고, 클릭만 하면 그 경계로 캡처, 드래그하면 직접 영역
- [ ] 휠 위/아래로 감지 범위가 넓어지고 좁아짐, Enter로 지금 잡힌 요소 캡처
- [ ] 설정에서 자동 감지를 끄면 영역 지정 캡처는 드래그만
- [ ] 제외 규칙(프로세스·창 이름)에 맞는 창은 감지되지 않음
- [ ] 관리자 권한 창·응답 없는 창 위에서도 앱이 멈추거나 꺼지지 않음 (창 경계까지만 잡힘)
- [ ] 커서 넣기 설정을 켜면 캡처에 화살표·글자 커서가 제 모양으로 들어감
- [ ] 영역 지정 중 Alt를 눌러도 화면이 고정되지 않음

## M4 스크롤 캡처 (시험 대상: 다운로드 폴더 탐색기 창)
- [x] 탐색기 목록을 골라 스크롤 캡처 → 세로로 이어 붙은 그림이 편집 창에 열림 (개발자: 스모크, 1213×9017)
- [ ] 트레이 "스크롤 캡처"·Ctrl+Alt+S로 시작, 커서 아래 스크롤되는 영역(목록·웹 페이지 본문)이 강조되고 클릭하면 자동으로 내려가며 찍음 (드래그 영역 지정 없음)
- [x] 크롬 네이버: 도구 막대를 뺀 페이지 본문이 잡히고 끝까지 이어 붙음, 따라붙는 검색창이 중간에 찍히지 않음 (개발자: 스모크)
- [x] 탐색기 파일 150개 목록: 목록만 잡히고 1~150이 빠짐·겹침 없이 이어짐 (개발자: 스모크)
- [ ] 휠로 바깥(창 전체)·안쪽(더 작은 영역)으로 바꿔 고를 수 있음, 스크롤 영역이 없는 곳은 창 전체
- [ ] 진행 표시 창에 길이가 늘어나고, 그 창은 결과 그림에 찍히지 않음
- [ ] 목록 끝에 닿으면 저절로 멈춤, Esc·클릭으로도 멈추고 그때까지 붙인 그림이 열림
- [ ] 이음매에 줄이 겹치거나 빠지지 않음 (파일 이름이 한 번씩만 나옴), 열 머리글은 맨 위에 한 번만
- [ ] 웹 페이지(브라우저)에서도 고정 머리글이 반복되지 않음
- [ ] 화면이 크게 바뀌면 "이어 붙이지 못한 곳에서 멈췄습니다" 알림과 함께 거기까지 열림

## GIF 녹화
- [ ] 영역 지정·요소 캡처 중 우클릭 = 메뉴가 뜨고 강조가 고정됨, "GIF 녹화"를 고르면 그 칸을 녹화
- [ ] 드래그 중 왼쪽 버튼을 누른 채 우클릭 = 끈 범위로 메뉴가 뜨고, 왼쪽 버튼을 떼도 캡처되지 않으며, "GIF 녹화"를 고르면 그 범위를 녹화
- [ ] 녹화하는 동안 그 범위 바깥에 빨간 테두리가 보이고, 테두리는 GIF에 찍히지 않으며 마우스가 테두리를 통과함 (모니터 가장자리에 붙은 범위는 그쪽 테두리가 화면 밖이라 안 보임)
- [ ] 메뉴를 Esc나 바깥 클릭으로 닫으면 영역 고르기로 돌아가고, 바깥 클릭이 캡처로 이어지지 않음
- [ ] 영역을 고를 때 조작 안내가 보이고, 캡처 결과·GIF에는 찍히지 않음. 환경설정에서 끌 수 있음
- [ ] 크롬에서 단축키 직후 커서를 움직이지 않아도 잠시 뒤 요소가 강조됨
- [x] GIF 녹화 첫 프레임에 영역 지정 화면이 찍히지 않음 (개발자: 스모크)
- [x] 커서가 GIF에 찍히고, 녹화 중 클릭이 대상 프로그램에 그대로 감 (개발자: 스모크)
- [x] Esc·멈춤 버튼·30초 한도로 끝나고 저장 창이 맨 앞에 뜸 (개발자: 스모크, Esc는 프로그램이 보낸 키로 시험)
- [ ] 직접 Esc를 눌러 멈춤, 멈춤 뒤 Esc가 대상 프로그램에 가지 않음
- [ ] 휠로 범위를 넓힌 뒤 우클릭 → GIF 녹화 = 그 범위를 녹화
- [ ] 자동 감지를 끄면 우클릭 → GIF 녹화 = 커서 아래 창 전체를 녹화
- [ ] 저장 창에서 취소 = 버릴지 한 번 더 묻고, 버리면 임시 파일도 남지 않음
- [ ] 그림·GIF를 저장하면 화면 오른쪽 아래에 알림 창이 뜨고 "열기"·"폴더 열기" 버튼이 있음. 열기 = 기본 프로그램, 폴더 열기 = 그 파일이 선택된 탐색기, 버튼 아닌 곳을 눌러도 열기. 6초 뒤 닫히고 마우스를 올려 두면 안 닫힘. 알림 창이 뜬 채 캡처해도 찍히지 않고, 편집 창의 키보드 입력을 빼앗지 않음
- [ ] 뒤에 있던 창을 우클릭해 녹화하면 그 창이 앞으로 나오고, 키보드 입력이 그 창으로 감
- [ ] 녹화 중 커서가 깜박이지 않음 (GIF와 실제 화면 모두)
- [ ] Esc를 길게 눌러 멈춰도 저장 창이 닫히지 않음
- [ ] "저장 시 묻지 않음" 설정이면 저장 폴더에 바로 저장되고 풍선 알림이 뜸
- [ ] 창 전체·전체 화면을 녹화해도 표시 창이 GIF에 찍히지 않음

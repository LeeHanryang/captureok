# M1 수동 확인 목록

표기: [x] 확인됨 (확인한 사람·방법), [~] 일부 확인, [ ] 미확인

## 트레이
- [x] 실행하면 트레이 아이콘이 생기고 설정 파일(`%APPDATA%\CaptureOk\settings.json`)이 만들어진다 (개발자, 실행 후 파일 확인)
- [x] 이미 실행 중일 때 다시 실행하면 두 번째는 바로 종료된다 (개발자, 프로세스·로그 확인)
- [x] 다른 프로그램이 단축키를 쓰고 있으면 로그와 트레이 알림에 실패한 키가 나온다 (개발자, PrintScreen 점유 상태에서 로그 확인)
- [ ] 트레이 메뉴 항목이 모두 보이고, 왼쪽 클릭 = 영역 지정 캡처
- [ ] "Windows 시작 시 자동 실행" 체크/해제 시 `HKCU\...\Run\CaptureOk` 값이 생기고 사라진다
- [ ] "저장 폴더 열기", "설정 파일 열기", "종료" 동작

## 영역 지정
- [~] PrintScreen(또는 Ctrl+Alt+R) → 두 모니터 모두 정지 화면이 어둡게 깔린다 (개발자: 당시 영역 지정 단축키로 오버레이가 약 0.1~0.25초 안에 맨 앞에 뜨는 것까지 확인, 화면 모습은 사용자 확인 필요)
- [ ] 드래그로 범위 지정, 선택 영역만 밝게, 크기 표시(`가로 × 세로`)
- [ ] 돋보기: 커서 주변 확대와 좌표 표시
- [ ] 방향키 1px, Shift+방향키 10px (선택 전 = 커서, 선택 후 = 영역 이동)
- [ ] Alt+방향키 = 선택 영역 크기 1px 조절
- [ ] 드래그 중 Ctrl = 천천히(1/8) 이동
- [ ] 드래그 중 Shift = 정사각형
- [~] Enter·더블클릭 = 확정, Esc = 취소, 우클릭 = 다시 선택 (선택 전이나 드래그 중이면 영역 지정·요소 캡처는 메뉴, 다른 방식은 취소) (개발자: Esc 취소 확인, 나머지 사용자 확인)
- [ ] 모니터 경계를 넘는 드래그가 하나의 결과로 잘린다

## 모드
- [ ] 창 캡처(Ctrl+Alt+W): 마우스 아래 창이 그림자 없이 강조, 클릭하면 그 창
- [x] 전체 화면(Ctrl+Alt+F): 커서가 있는 모니터 (개발자: 2560×1440 결과 확인)
- [~] 고정 크기(Ctrl+Alt+Z): 고정 크기 사각형이 커서를 따라다니고 클릭 = 확정, 숫자키 1~9 = 크기 목록 전환 (개발자: Enter로 커서 중심 1280×720 확정 확인)
- [~] 직전 영역(Ctrl+Alt+L): 마지막 영역을 바로 캡처 (처음엔 주 모니터 중앙 800×450) (개발자: 바로 편집 창이 뜨는 것 확인)
- [ ] 요소 캡처(Ctrl+Alt+E): M1에선 영역 지정과 같음
- [ ] 스크롤(Ctrl+Alt+S): (M4에서 구현됨)

## 편집 창
- [ ] 캡처 후 편집 창이 캡처 위치 근처에 최상위로 뜬다
- [x] Ctrl+S: 저장 폴더에 `날짜_시간.png`, 트레이 알림 후 창 닫힘 (개발자: 20261027_190247.png 생성·창 닫힘 확인, 알림 모습은 사용자 확인)
- [ ] 같은 초에 두 번 저장 → `_1` 이 붙는다
- [ ] Ctrl+Shift+S: 위치·이름 선택 저장
- [ ] Ctrl+C: 클립보드 복사 후 창 닫힘, 그림판에 붙여넣기 확인
- [ ] 저장 폴더를 쓸 수 없는 경로로 바꾸면 오류 안내 후 다른 이름으로 저장 창, 편집 창은 유지
- [ ] 편집 창 두 개를 동시에 띄울 수 있다
- [x] Esc: 닫기 (개발자)

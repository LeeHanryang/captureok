# CaptureOK 설치 가이드

## 필요한 것

- Windows 10(1809 이상) 또는 Windows 11, 64비트
- 관리자 권한은 필요 없습니다. .NET 같은 다른 프로그램도 따로 설치하지 않아도 됩니다.

## 설치하기

1. [Releases](../../../releases) 페이지에서 가장 최신 버전의 `CaptureOK-Setup-<버전>.exe`를 받습니다.
2. 받은 파일을 실행합니다.
3. **"Windows의 PC 보호" 파란 창이 뜨면** — 코드 서명이 없는 새 프로그램이라 처음 몇 번은 이 창이 뜰 수 있습니다.
   **추가 정보**를 누른 뒤 **실행**을 누르세요. (받은 곳이 이 저장소의 Releases가 맞는지 먼저 확인하세요.)
4. 설치 화면에서 고를 수 있는 것:
   - **Windows 시작 시 자동 실행** (기본 켜짐) — 켜 두면 PC를 켤 때 트레이에 바로 떠 있어 단축키를 쓸 수 있습니다.
   - **바탕 화면에 바로 가기 만들기** (기본 꺼짐)
5. 설치가 끝나면 CaptureOK가 실행되고, 화면 오른쪽 아래 트레이(알림 영역)에 아이콘이 생깁니다.
   아이콘이 안 보이면 트레이의 `^`(숨겨진 아이콘 표시)를 눌러 보세요.

설치 위치: `%LOCALAPPDATA%\Programs\CaptureOk` (지금 사용자 계정에만 설치)

## 처음 쓸 때

- `PrtSc` 또는 `Ctrl+Alt+R`을 누르면 영역 지정 캡처가 시작됩니다. 왼쪽 클릭은 강조된 부분, 드래그는 고른 범위, 가운데 버튼(휠) 클릭은 스크롤 캡처, 우클릭은 메뉴(GIF 녹화)입니다. 취소는 `Esc`이고, 조작 안내가 화면에 함께 보입니다. 그 밖의 단축키는 [README](../README.md#주요-기능)를 보세요.
- 트레이 아이콘을 오른쪽 클릭하면 캡처 방식·캡처 목록·저장 폴더·환경설정·종료 메뉴가 있습니다.
- **PrtSc 키를 눌러도 Windows 캡처 도구가 뜨는 경우**: Windows 설정 > 접근성 > 키보드 >
  "Print Screen 키를 사용하여 화면 캡처 열기"를 끄면 CaptureOK가 PrtSc 키를 받습니다.
- **단축키가 다른 프로그램과 겹치는 경우**: CaptureOK 시작 때 알려 주며, 환경설정 > 단축키에서 바꿀 수 있습니다.
  (예: 그래픽 드라이버 도구나 메신저가 `Ctrl+Alt` 조합을 쓰고 있으면 겹칠 수 있습니다.)

## 업데이트하기

새 버전의 설치 파일을 받아 그대로 실행하면 됩니다. 설정과 고정한 캡처는 그대로 남습니다.
CaptureOK가 켜져 있으면 설치 프로그램이 끌지 묻습니다 — 저장하거나 복사하지 않은 캡처는 사라지니 먼저 저장하세요.

## 제거하기

Windows 설정 > 앱 > 설치된 앱에서 **CaptureOK**를 찾아 **제거**를 누릅니다.

- 제거할 때 "환경설정과 고정한 캡처도 지울까요?"를 묻습니다. 기본은 **아니요**(남겨 둠)입니다.
- 저장 폴더에 저장한 그림 파일은 어느 경우에도 지우지 않습니다.

## 파일이 저장되는 곳

| 내용 | 위치 |
|---|---|
| 프로그램 | `%LOCALAPPDATA%\Programs\CaptureOk` |
| 환경설정·기록(로그) | `%APPDATA%\CaptureOk` (`settings.json`, `captureok.log`) |
| 고정한 캡처 | `%LOCALAPPDATA%\CaptureOk\pinned` |
| 저장한 그림 (기본) | `사진\CaptureOk` — 환경설정 > 저장에서 바꿀 수 있습니다 |

## 문제가 생기면

- 트레이 아이콘을 오른쪽 클릭 > **종료** 후 다시 실행해 보세요.
- 이 저장소의 Issues에 증상과 `%APPDATA%\CaptureOk\captureok.log` 내용을 함께 올려 주시면 도움이 됩니다.
  (로그에는 저장한 파일 경로 — 사용자 이름이 들어간 폴더 이름 등 — 이 들어갈 수 있으니 올리기 전에 한 번 확인해 주세요.)
